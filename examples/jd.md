# 京东App搜索功能需求文档 (PRD)

**版本：** v1.0

**状态：** 推进中

**负责人：** 京东搜索产品组

---

## 1. 项目背景与目标

* **背景：** 搜索是京东App流量分配的核心入口，承载超过 70% 的转化交易量。
* **目标：** 优化用户搜索路径，提升搜索词与商品的匹配精度（Relevance），提高转化率（CVR）及客单价。

---

## 2. 用户核心路径

1. **激活搜索框：** 点击首页搜索框，进入搜索中间页。
2. **输入/联想：** 输入关键词，查看联想词或直接发起搜索。
3. **浏览结果：** 进入搜索结果页（SRP），查看商品列表。
4. **筛选/排序：** 通过筛选工具缩小范围。
5. **决策跳转：** 点击商品进入商详页（PDP）。

---

## 3. 功能需求详述

### 3.1 搜索入口与中间页

| 功能点 | 需求描述 | 逻辑说明 |
| --- | --- | --- |
| **搜索框** | 默认展示热搜词（Placeholder） | 基于用户画像与大盘热度动态更新。 |
| **搜索历史** | 展示最近10条搜索记录 | 支持单条删除及清空，超过两行自动折叠。 |
| **热搜榜单** | 展示Top 10热门搜索词 | 增加运营权重标签（如：新、热、省）。 |
| **多模态搜索** | 扫一扫、拍照购入口 | 调用摄像头进行图像识别匹配。 |

### 3.2 搜索联想（Suggest）

* **触发机制：** 用户输入第一个字符起触发。
* **展示内容：**
* **关键词匹配：** 联想出包含关键词的完整商品词。
* **直达区：** 匹配到特定品牌、店铺或活动时，直接展示跳转入口。
* **分类引导：** 提示“在 [电脑] 分类下搜索”。



### 3.3 搜索结果页 (SRP)

#### **A. 排序逻辑**

* **综合排序（默认）：** 算法加权排序（相关度 x 销量 x 评价 x 京东物流权重 x 广告投放）。
* **单维排序：** 支持按“销量”、“价格”、“评价数”、“新品”进行升降序切换。

#### **B. 筛选体系**

* **快筛标签：** 京东物流、自营、有货、促销活动（满减/优惠券）。
* **层级筛选：**
* **基础：** 品牌、分类、价格区间。
* **参数（类目特有）：** 如手机类目的“内存大小”、“电池容量”。



#### **C. 样式展示**

* **大图模式/列表模式：** 支持用户手动切换单列或双列展示。
* **属性透传：** 关键信息（如“99%好评”、“百亿补贴”、“24H发货”）在列表页外显。

---

## 4. 非功能性需求

* **性能：** 搜索首屏加载时间（LCP）需控制在 **1.2s** 以内。
* **纠错能力：** 具备模糊纠错功能（如输入“苹果手几”自动修正为“苹果手机”）。
* **无结果处理：** 若搜无结果，展示“猜你喜欢”推荐内容，避免死胡同。

---

## 5. 数据埋点需求

1. **搜索词分布：** 统计高频搜索词、无结果搜索词。
2. **点击率（CTR）：** 各位置搜索结果的点击分布。
3. **转化率（CVR）：** 搜索词 -> 下单的最终转化漏斗。
4. **筛选器使用率：** 各个筛选维度的热度。
