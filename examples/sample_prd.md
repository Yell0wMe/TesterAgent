# PRD 示例：电商登录模块

版本：v1.0
产品负责人：产品经理
目标读者：研发/测试

---

## 1. 功能概述

本模块实现用户登录功能，支持手机号+验证码登录方式。

---

## 2. 登录流程

### 2.1 主流程

用户打开APP后，点击"登录"按钮进入登录页面。

**成功标准：**
- 页面显示"登录"标题
- 显示手机号输入框和验证码输入框
- 显示"获取验证码"按钮

### 2.2 获取验证码

用户输入手机号后，点击"获取验证码"按钮。

**前置条件：**
- 手机号格式正确（11位数字）

**成功标准：**
- 显示"验证码已发送"提示
- "获取验证码"按钮变为倒计时状态（60秒）

**异常情况：**
- 手机号格式错误：显示"请输入正确的手机号"
- 发送频率过高：显示"操作过于频繁，请稍后再试"

### 2.3 提交登录

用户输入验证码后，点击"登录"按钮完成登录。

**前置条件：**
- 已输入手机号
- 已输入6位验证码

**成功标准：**
- 登录成功后跳转至首页
- 首页显示用户头像
- 显示"登录成功"Toast提示

**异常情况：**
- 验证码错误：显示"验证码错误，请重新输入"
- 验证码过期：显示"验证码已过期，请重新获取"
- 账号被封禁：显示"账号异常，请联系客服"

---

## 3. 安全要求

- 验证码输入错误超过5次，需等待10分钟后重试
- 不得泄露用户手机号到日志
- 登录接口需要防刷限流

---

## 4. 接口说明

### 4.1 发送验证码

```
POST /api/auth/send-code
Request: { "phone": "13800138000" }
Response: { "success": true, "message": "验证码已发送" }
```

### 4.2 登录验证

```
POST /api/auth/login
Request: { "phone": "13800138000", "code": "123456" }
Response: { "success": true, "token": "xxx", "user": {...} }
```
