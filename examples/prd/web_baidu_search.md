# 百度搜索功能验收需求文档

## 1. 文档信息
- **文档ID**: PRD_WEB_BAIDU_001
- **版本**: v1.0
- **目标应用**: 百度Web版
- **目标URL**: https://www.baidu.com

## 2. 功能列表

### 2.1 首页加载与搜索
**用户目标**: 用户能够打开百度首页并进行关键词搜索。

**正常场景**:
1. 用户访问 https://www.baidu.com。
2. 页面加载完成，显示百度Logo和搜索输入框。
3. 用户在输入框中输入 "TesterAgent"。
4. 点击 "百度一下" 按钮。
5. 页面跳转至搜索结果页，包含 "TesterAgent" 相关条目。

**成功标准**:
- 首页包含 "百度一下" 按钮。
- 搜索结果页标题包含 "TesterAgent"。
- 搜索结果页出现 "相关搜索" 或列表项。

### 2.2 搜索联想 (可选)
**用户目标**: 输入部分关键词时显示联想词。

**正常场景**:
1. 输入 "Pyt"。
2. 下拉框显示 "Python", "Pytorch" 等联想词。
